# Skill: GenAI, RAG & Agents

## Purpose
Design grounded generative AI experiences where language understanding, synthesis, reasoning, or tool-use is central.

## Outputs
- User task
- Knowledge/data grounding sources
- Retrieval pattern
- Tool/action boundaries
- Prompt/system behavior
- Evaluation set
- Safety and permission model
- Human approval points
- Cost/latency targets

## Use when
- Knowledge assistants
- Conversational analytics
- Document intelligence
- Agentic workflow assistance

## Do not use when
Deterministic SQL/BI/rules solve the problem more reliably.
