# Skill: BI, Semantic & Analytics

## Purpose
Deliver governed metrics, exploration, dashboards, and semantic experiences when the core problem is analytical rather than predictive.

## Outputs
- KPI definition layer
- Metric grain
- Semantic model
- Dashboard/user journey
- Drill paths
- Freshness requirements
- BI serving architecture

## Use when
- Executive reporting
- Operational dashboards
- Self-service analytics
- KPI standardisation

## Rule
A dashboard must answer a decision question and lead to an action or insight.
