# Retail Example — How to Use the Toolkit

Example prompt:

> We are meeting a retailer whose category managers receive inventory and sales information from multiple systems and discover stock-out risks too late. Help me prepare the engagement and propose a prototype.

Suggested sequence:

1. `@customer-discovery`
2. `@value-mapping`
3. `@solution-architecture`
4. `@prototype-planner`
5. `@synthetic-data-generator` if real data is unavailable
6. `@gold-analytical-modeling` for business metrics
7. `@genie-agent-integration` only if conversational analytics is appropriate
8. `@demo-storytelling`
9. `@poc-design`

The example deliberately does not prescribe Genie, streaming, medallion, or GenAI before requirements justify them.
